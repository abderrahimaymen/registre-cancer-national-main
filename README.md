# CancerTrack National

A national cancer registry platform for managing patient records, clinical data, laboratory workflows, role-based access, and cancer analytics.

## Features

- Secure authentication and role-based access control
- Patient registration and clinical record management
- Cancer diagnosis and tumor tracking
- Laboratory requests and structured results
- Research dashboards and cancer statistics
- Wilaya-based maps and risk-zone visualization
- Duplicate patient detection and record merging
- Audit logs for traceability
- Light and dark themes

## Technology Stack

- React
- TypeScript
- Vite
- React Router
- Axios
- Recharts
- React Leaflet
- Framer Motion
